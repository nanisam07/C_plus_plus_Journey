## ▶️ How to Run

Make sure GCC is installed and available in your terminal.

Compile a program:

```bash
g++ main.cpp -o main.exe
```

Run it in Windows PowerShell:

```powershell
.\main.exe
```

On Linux or macOS, compile and run using:

```bash
g++ main.cpp -o main
./main
```

Replace `main.cpp` with the filename of the program you want to execute.
